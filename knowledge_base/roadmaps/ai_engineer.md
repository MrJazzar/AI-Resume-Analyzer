# AI Engineer Roadmap

## Career Goal
An AI Engineer builds software that uses machine learning models, data pipelines, APIs, and reliable production systems.

## Recommended Learning Order

1. Python fundamentals: data types, functions, modules, exceptions, object-oriented programming, and virtual environments.
2. Software engineering: Git, testing with pytest, type hints, clean code, debugging, and basic software architecture.
3. Data skills: SQL, data cleaning, pandas, NumPy, and basic statistics.
4. Machine learning: supervised learning, unsupervised learning, model evaluation, feature engineering, and scikit-learn.
5. Deep learning: neural networks, training loops, embeddings, transformers, and PyTorch.
6. APIs and deployment: FastAPI, REST APIs, Docker, environment variables, logging, and cloud deployment basics.
7. Production AI: vector databases, retrieval augmented generation, prompt design, evaluation, monitoring, and responsible AI.

## Beginner Milestone
Build a Python project with tests, type hints, a README, and a clear package structure.

## Intermediate Milestone
Train and evaluate a machine learning model, expose it through a FastAPI endpoint, and package it with Docker.

## Advanced Milestone
Build a RAG application with document ingestion, embeddings, retrieval, answer generation, source citations, evaluation, and monitoring.

## Portfolio Evidence
A strong portfolio should show the problem, data, architecture, implementation decisions, test coverage, deployment steps, and measurable results.
