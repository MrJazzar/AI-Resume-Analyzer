# AI Engineer Resume Guidelines

## Resume Structure

Use a one-page resume for junior candidates when possible. Put contact details, a concise summary, technical skills, experience, projects, education, and certifications in a clear order.

## Professional Summary

Write two or three lines that identify the target role, strongest technical abilities, and the kind of systems or models you build. Avoid generic claims such as hard worker without evidence.

## Skills Section

Group skills by category:

- Programming: Python, SQL, Git
- Data: NumPy, pandas, statistics
- Machine learning: scikit-learn, model evaluation, feature engineering
- Deep learning: PyTorch, neural networks, transformers
- Backend and deployment: FastAPI, REST, Docker, Linux
- AI systems: embeddings, vector databases, RAG, prompt evaluation

Only list skills that can be demonstrated in a project or discussed in an interview.

## Project Bullet Formula

Use: action + technical method + measurable result.

Example: Built a FastAPI resume matching service using embeddings and cosine similarity, added 25 integration tests, and reduced manual screening time for the sample workflow.

## Project Details to Include

For each project, explain the problem, data source, architecture, important tools, evaluation method, deployment approach, and one measurable result. Link to a clean repository when available.

## Improvement Checklist

- Replace task descriptions with results and measurements.
- Mention testing, validation, and error handling.
- Explain model metrics and the evaluation dataset.
- Show deployment skills with Docker or a hosted demo.
- Remove unrelated skills and outdated technologies.
- Keep formatting consistent and make the resume easy to scan.

## Certifications

Certifications are optional. Prioritize a strong project portfolio and practical evidence. If a certification is relevant, explain the skills it validates and connect it to a project. Avoid listing certificates without showing applied work.
